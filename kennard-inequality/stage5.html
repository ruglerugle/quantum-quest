STAGE 5魔法の関数 I(λ)
証明はこうして発見される
🎯 ミッション
「2乗和は0以上」という狩りの型と「ゴールからの逆算」を使って、証明の心臓 I(λ)＝∫|λxψ＋ψ′|²dx を自分で発見し、展開して (Δx)²λ²−λ＋(Δp)²/ℏ² ≥ 0 まで磨き上げよう。
未達成
ねこ博士
いよいよ山場だよ。教科書だと、ここで天から降ってきたように「I(λ)＝∫|λxψ＋ψ′|²dx を考える」と書いてあって、読者は面食らうことになる。でも今日は順番を変えて、この式をどうやったら自分で思いつけるのか、発見の論理をたどろう。まずは準備運動だ。数学の質問：どんな実数 a, b についても a²＋b² ≥ 2ab が成り立つ。これを証明できるかな。ヒントは、きみが STAGE1 で言った「2乗すれば0以上になる」だよ。
うさ美
2乗は必ず0以上……。それなら (a−b)² ≥ 0 は文句なしに正しいです。左辺を展開すると a²−2ab＋b² ≥ 0。2ab を右に移項して、a²＋b² ≥ 2ab。……できました。というより、展開して移項しただけです。証明ってこんなにあっけないものなんですか？
ねこ博士
あっけないのに、これが不等式証明の王道の型なんだ。手順を抜き出すとこうなる。①明らかに0以上の量（2乗）を仕込む → ②展開する → ③欲しい不等式が転がり出る。「大小関係はどこから来るのか」というきみの前ステージの問いの答えがこれだよ。世界中の不等式のかなりの部分が、この型の親戚で証明されている。1821年、コーシーは有名な不等式をまさにこの型で証明したし、後にシュワルツが積分の世界に拡張した。19世紀の数学者にとって、これは誰もが腰に差している剣だったんだ。
うさ美
型は分かりました。私たちの獲物は Δx·Δp ≥ ℏ/2。この型で狩るなら、「明らかに0以上の量」をうまく仕込んで、展開したら Δx と Δp が出てくるようにすればいい。……問題は、何を2乗するかですね。それが分からないと始まりません。
ねこ博士
そこでゴールからの逆算だ。道具箱の式を、少しだけ書き直して見比べてごらん。(Δx)²＝∫x²|ψ|²dx は、x²|ψ|²＝|xψ|² だから、「関数 xψ の2乗の積分」と読める。補題2の (Δp)²＝ℏ²∫|ψ′|²dx は、「関数 ψ′ の2乗の積分」。……気づくことはないかな。
うさ美
両方とも「何かの2乗の積分」！ Δx を担当するのが xψ という関数で、Δp を担当するのが ψ′ という関数。それなら、2乗して仕込むべきものは決まりです。xψ と ψ′ を混ぜたものを2乗すれば、展開したときに |xψ|² の項と |ψ′|² の項――つまり (Δx)² と (Δp)² が両方出てきます。(a−b)² から a² と b² が出てきたのと同じ仕組みで！
ねこ博士
それが答えの9割だよ。仕上げにプロの工夫を1つ足そう。混ぜるとき、配合比を固定せず、自由に調整できるつまみ λ（ラムダ）を付けておくんだ。λxψ＋ψ′ という混合物を作って、その2乗を積分する。これが魔法の関数 I(λ) だよ。どんな実数 λ を選んでも、中身は絶対値の2乗――0以上の量の足し合わせだから、I(λ) ≥ 0 は無条件で正しい。つまり、λ の数だけ無限個の不等式が一度に手に入る。後でいちばん強いものを選び抜けばいい。
【魔法の関数】
I(λ) ＝ ∫ |λxψ(x) ＋ ψ′(x)|² dx ≥ 0　（すべての実数 λ で成り立つ） 仕込みの理由：
(Δx)²＝∫|xψ|²dx、 (Δp)²/ℏ²＝∫|ψ′|²dx　――ゴールの2人が「2乗の積分」で並んでいる
うさ美
ひとつ引っかかることがあります。なぜ「足し算」で混ぜるとうまくいくと信じられるんでしょう。xψ と ψ′ なんて、全然違う種類の関数に見えます。混ぜてもぐちゃぐちゃになるだけかもしれないのに。
ねこ博士
最高の質問だ。ここに、発見の物語のいちばん美しい伏線が隠れているんだよ。実はハイゼンベルクは1927年の論文で、釣鐘型のガウス波束という具体的な波について Δx·Δp を計算して、ちょうど ℏ/2 になることを確かめていた。もし ℏ/2 が本当の下限なら、ガウス波束は「これ以上縮められない最良の波」ということになる。ではガウス型 ψ＝e−ax² を微分してみてごらん。指数の微分の規則で、肩の −ax² の微分 −2ax が前に降りてくるから――
うさ美
ψ′ ＝ −2ax·e−ax² ＝ −2a×(xψ)。……！ 驚きました。ガウス波束では、ψ′ と xψ は定数倍しか違わない、実質同じ関数なんですね。ということは λ＝2a と選べば λxψ＋ψ′ はぴったり0、つまり I(λ)＝0。魔法の関数は、「最良の波からのズレ」を測る物差しだったんだ。最良の波ならズレはゼロ、それ以外の波では必ずプラス……。ぐちゃぐちゃどころか、この2つは混ぜるために生まれてきたような組み合わせです。
ガウス波束 ψ＝e−ax² では ψ′＝−2a·xψ。上の2本は上下が逆なだけの同じ形で、λ＝2a と選んで足すと完全に打ち消し合う。I(λ) は「最良の波（ガウス波束）からのズレ」を測っている
ねこ博士
見抜いたね。では狩りの型の②、展開に進もう。複素数の2乗の展開公式は |A＋B|²＝(A＋B)(A*＋B*)＝|A|²＋AB*＋A*B＋|B|²。A＝λxψ、B＝ψ′ を入れる。λ も x も実数だから A*＝λxψ* となって、真ん中の2項は λx(ψψ′*＋ψ*ψ′) とまとまるよ。
うさ美
括弧の中の ψψ′*＋ψ*ψ′、これ、見覚えがあります。積の微分公式です！ |ψ|²＝ψψ* を微分すると (ψψ*)′＝ψ′ψ*＋ψ(ψ*)′。同じものです。つまり真ん中の項は λx(|ψ|²)′。……あっ、だから補題1だったんですね。∫x(|ψ|²)′dx が証明のどこで出てくるのか不思議でしたが、ここで登場するために仕込んであったんだ。
ねこ博士
伏線回収だよ。それでは積分して、3つの項を道具箱の言葉に翻訳してごらん。λ² の項、λ の項、定数項の順でね。
うさ美
λ² の項は λ²∫x²|ψ|²dx ＝ (Δx)²λ²。λ の項は λ∫x(|ψ|²)′dx で、補題1からこの積分は −1、だから −λ。定数項は ∫|ψ′|²dx で、補題2から (Δp)²/ℏ²。全部そろって……I(λ) ＝ (Δx)²λ² − λ ＋ (Δp)²/ℏ²。これが、どんな λ でも0以上。
ねこ博士
立ち止まって、いま起きたことの凄みを味わってほしい。出発点には波動関数 ψ――無限にありうる、あらゆる波の形――がいた。ところが展開して道具箱で翻訳したら、ψ は式から完全に消えてしまった。残ったのは Δx と Δp という2つの数と、つまみ λ だけの、ただの二次関数だ。無限にある波の形を一網打尽にする仕掛けの正体はこれだよ。どんな ψ から出発しても、必ずこの同じ二次関数の形に流れ込む。
展開：
|λxψ＋ψ′|² ＝ λ²x²|ψ|² ＋ λx(|ψ|²)′ ＋ |ψ′|²　（真ん中は積の微分公式で束ねた） 積分して道具箱で翻訳： 　λ²∫x²|ψ|²dx ＝ (Δx)²λ²　／　λ∫x(|ψ|²)′dx ＝ −λ（補題1）　／　∫|ψ′|²dx ＝ (Δp)²/ℏ²（補題2） 【到達点】
I(λ) ＝ (Δx)²λ² − λ ＋ (Δp)²/ℏ² ≥ 0　（すべての実数 λ で）
うさ美
「どんな λ を入れても0以上になる二次関数」……。グラフで言えば、下に凸の放物線が、横軸より下に一度も潜らないということですよね。放物線がそういう形になれる条件なら、学校で習った道具で書けそうな気がします。
ねこ博士
その通り、次のステージはきみのホームグラウンドだ。1927年の物理学の最深部に、中学校の数学がとどめを刺しに行くよ。
確認クイズ

Q1. I(λ)＝∫|λxψ＋ψ′|²dx が、どんな λ でも必ず0以上になる理由は？

正解！ 「2乗は0以上」――STAGE1でばらつきを定義したときと同じ、いちばん素朴な事実が証明全体を支えている。(a−b)²≥0 から a²+b²≥2ab を出した狩りの型の、積分版だ。

Q2. 2乗する中身として「xψ と ψ′ の混合」を選ぶ理由は？

正解！ 展開すれば |xψ|² と |ψ′|² の項が現れて、狙い通り (Δx)² と (Δp)² が式に登場する。さらにガウス波束では ψ′∝xψ なので、この混合は「最良の波からのズレ」という意味まで持っている。

Q3. 展開後の式 (Δx)²λ² − λ ＋ (Δp)²/ℏ² に現れる「−λ」の係数 −1 の出どころは？

正解！ 「電子は必ずどこかにいる」という規格化条件が、部分積分を経由して −1 という数に化け、λ の1次の係数として証明の急所に座る。どんな波形でも同じ −1 になるのがポイントだ。
