魔法の関数 I(λ)

証明はこうして発見される
🎯 ミッション
「2乗和は0以上」という狩りの型と「ゴールからの逆算」を使って、証明の心臓 I(λ)＝∫|λxψ＋ψ′|²dx を自分で発見し、展開して (Δx)²λ²−λ＋(Δp)²/ℏ² ≥ 0 まで磨き上げよう。
未達成
ねこ博士
いよいよ山場だよ。教科書だと、ここで天から降ってきたように「I(λ)＝∫|λxψ＋ψ′|²dx を考える」と書いてあって、読者は面食らうことになる。でも今日は順番を変えて、この式をどうやったら自分で思いつけるのか、発見の論理をたどろう。まずは準備運動だ。数学の質問：どんな実数 a, b についても a²＋b² ≥ 2ab が成り立つ。これを証明できるかな。手がかりは、STAGE1 で書き留めた「2乗した量は、どんな実数でも0以上」だよ。
うさ美
2乗は必ず0以上……。それなら (a−b)² ≥ 0 は文句なしに正しいです。左辺を展開すると a²−2ab＋b² ≥ 0。2ab を右に移項して、a²＋b² ≥ 2ab。……できました。というより、展開して移項しただけです。証明ってこんなにあっけないものなんですか？
ねこ博士
あっけないのに、これが不等式証明の王道の型なんだ。手順を抜き出すとこうなる。①明らかに0以上の量（2乗）を仕込む → ②展開する → ③欲しい不等式が転がり出る。「大小関係はどこから来るのか」というきみの前ステージの問いの答えがこれだよ。世界中の不等式のかなりの部分が、この型の親戚で証明されている。1821年、コーシーは有名な不等式をまさにこの型で証明したし、後にシュワルツが積分の世界に拡張した。19世紀の数学者にとって、これは誰もが腰に差している剣だったんだ。
うさ美
型は分かりました。私たちの獲物は Δx·Δp ≥ ℏ/2。この型で狩るなら、「明らかに0以上の量」をうまく仕込んで、展開したら Δx と Δp が出てくるようにすればいい。……問題は、何を2乗するかですね。それが分からないと始まりません。
ねこ博士
そこでゴールからの逆算だ。道具箱の式を、少しだけ書き直して見比べてごらん。(Δx)²＝∫x²|ψ|²dx は、x²|ψ|²＝|xψ|² だから、「関数 xψ の2乗の積分」と読める。補題2の (Δp)²＝ℏ²∫|ψ′|²dx は、「関数 ψ′ の2乗の積分」。……気づくことはないかな。
うさ美
両方とも「何かの2乗の積分」！ Δx を担当するのが xψ という関数で、Δp を担当するのが ψ′ という関数。それなら、2乗して仕込むべきものは決まりです。xψ と ψ′ を混ぜたものを2乗すれば、展開したときに |xψ|² の項と |ψ′|² の項――つまり (Δx)² と (Δp)² が両方出てきます。(a−b)² から a² と b² が出てきたのと同じ仕組みで！
ねこ博士
それが答えの9割だよ。仕上げにプロの工夫を1つ足そう。混ぜるとき、配合比を固定せず、自由に調整できるつまみ λ（ラムダ）を付けておくんだ。波長にも同じ文字を使ったけれど、あれとは無関係の、ただの数だと思ってほしい。ここから先、λ はいつもこの「つまみ」を指す。λxψ＋ψ′ という混合物を作って、その2乗を積分する。これが魔法の関数 I(λ) だよ。どんな実数 λ を選んでも、中身は絶対値の2乗――0以上の量の足し合わせだから、I(λ) ≥ 0 は無条件で正しい。つまり、λ の数だけ無限個の不等式が一度に手に入る。後でいちばん強いものを選び抜けばいい。
【魔法の関数】
I(λ) ＝ ∫ |λxψ(x) ＋ ψ′(x)|² dx ≥ 0　（すべての実数 λ で成り立つ） 仕込みの理由：
(Δx)²＝∫|xψ|²dx、 (Δp)²/ℏ²＝∫|ψ′|²dx　――ゴールの2人が「2乗の積分」で並んでいる
うさ美
ひとつ引っかかることがあります。なぜ「足し算」で混ぜるとうまくいくと信じられるんでしょう。xψ と ψ′ なんて、全然違う種類の関数に見えます。混ぜてもぐちゃぐちゃになるだけかもしれないのに。
ねこ博士
いい質問だね。ここに、発見の物語のいちばん美しい伏線が隠れているんだよ。その前に、役者を1人紹介しておこう。ガウス波束だ。量子力学の教室で、位置の決まった波は「いろいろな波長の波を混ぜて作る波束」だと見たね。波束の山の形はいろいろありうるが、その中で山が釣鐘型――真ん中がいちばん高く、左右対称で、裾に向かってなだらかに、しかし速やかに 0 へ落ちていく形――になっているものを、ガウス波束と呼ぶ。式で書くと ψ＝A·e−ax²。肩の −ax² は真ん中 x＝0 で 0 だから e0＝1 で最大、真ん中から離れるほど大きなマイナスになって 0 へ落ちる。a は山の幅を決めるつまみで、a が大きいほど山は細い。前に付けた A は、規格化条件「|ψ|² の面積が 1」を満たすための定数だ。山を細くすれば、面積を 1 に保つために山は高くならなければいけないから、A は a で決まる（計算すると A＝(2a/π)1/4）。ただの定数倍だから、山の形には関係しない。「ガウス」の名は STAGE1 の誤差論から来ている。星の位置を何度も測ったときの誤差の散らばりが、まさにこの釣鐘の形になることをガウスが示したんだ。
1.00
ガウス波束 ψ＝A·e−ax²（金）と、その確率密度 |ψ|²＝A²e−2ax²（赤）。どちらも真ん中が最も高く、左右対称で、裾が速やかに 0 へ落ちる釣鐘型。A＝(2a/π)1/4 は規格化のための定数で、赤い山の面積は a をどう変えても 1――だから山を細くするほど高くなる。a を大きくすると山は細くなり、位置の標準偏差 Δx＝1/(2√a) は小さくなる。いっぽう細い山を作るには多くの波長を混ぜる必要があるので、運動量の標準偏差 Δp＝ℏ√a は大きくなる。積 Δx·Δp は a をどう選んでも ℏ/2 ぴったり――ハイゼンベルクが1927年の論文で確かめたのは、この計算だった
うさ美
STAGE1 の誤差の釣鐘が、今度は波の形として戻ってくるんですね。a を大きくすると山が細くなる――位置がよく決まった波束、ということですか。
ねこ博士
そう。そして実はハイゼンベルクは1927年の論文で、このガウス波束について Δx·Δp を計算して、ちょうど ℏ/2 になることを確かめていた。もし ℏ/2 が本当の下限なら、ガウス波束は「これ以上縮められない最良の波」ということになる。ここから、きみの疑問への答えが逆算できるんだ。ガウス波束で Δx·Δp＝ℏ/2 と等号が成り立つなら、それを導く途中の不等式 I(λ) ≥ 0 も、ガウス波束ではどこかの λ で等号 I(λ)＝0 になっていなければつじつまが合わない。途中に隙間があれば、最後にも隙間が残るからね。ところが I(λ) は 0 以上の量の足し合わせだから、0 になるには中身の λxψ＋ψ′ がどこでも 0、言い換えると ψ′ が xψ のちょうど定数倍でなければならない。きみが「全然違う種類」と言った2つの関数が、ガウス波束の上では定数倍の関係にある――そう予言できる。本当かどうか、微分して確かめよう。ガウス型 ψ＝A·e−ax² を微分する。定数 A はそのまま前に残る。肩の −ax² を微分すると −2ax（x² の傾きは 2x だからね）。これが前に降りてきて、ψ′＝−2ax·A·e−ax²。
うさ美
待ってください。eikx のときは「微分すると ik が前に出る」と習いました。あれは肩の ikx から係数の ik を取り出しただけに見えましたけど、いまの計算では肩 −ax² を微分したものを前に出しています。「肩を微分したものが前に降りる」というのは初めてです。なぜそうなるんですか？
ねこ博士
いいところに引っかかったね。さらっと使ってしまったが、ここは確かめておく価値がある。実は平面波のときも、前に出ていた ik は「肩 ikx を微分したもの」だったんだ。肩の傾きが一定だったから、係数を取り出しただけに見えていた。肩が −ax² のように曲がった式でも通用する規則として、組み立て直そう。ψ＝ef(x) と書いて、x を少しだけ Δx 進める。まず肩 f は、STAGE4 でやったとおり「傾き × 進んだ幅」で Δf ≈ f′(x)·Δx だけ変わる。次に、肩が Δf 変わると ef はどうなるか。肩の足し算は掛け算だから ef＋Δf＝ef·eΔf。そして e は「傾きが自分の高さのちょうど1倍」の数だったね。eu は u＝0 で高さ 1、傾きも 1。だから u が小さな Δf だけ進めば eΔf ≈ 1＋Δf。合わせると、ψ の増分は Δψ ＝ ef(eΔf−1) ≈ ef·Δf ＝ ef·f′(x)·Δx。Δx で割れば ψ′＝f′(x)·ef(x)――「肩を微分したものが前に降りてきて、e の部分はそのまま残る」。ψ の傾きは「肩の傾き × 自分の高さ」というわけだ。平面波は f′＝ik の特別な場合だったんだね。だからガウス型では、肩 −ax² の微分 −2ax が前に降りる。
＋0.60
上：肩 f(x)＝−ax²（a＝1）。x を Δx 進めると肩は Δf ≈ f′(x)·Δx（傾き × 幅）だけ変わる。下：ψ＝ef(x)。肩が Δf 変わると ψ は eΔf ≈ 1＋Δf 倍、つまり ψ·Δf だけ増える。2つを合わせれば Δψ ≈ ψ·f′(x)·Δx で、ψ の傾き ＝ 肩の傾き f′(x) × 自分の高さ ψ。読み出しでは、この掛け算の値と、曲線から直接測った傾きが一致することを確かめられる。平面波 eikx は肩の傾きが ik で一定という特別な場合
【e の肩に式が乗っているときの微分】
ψ＝ef(x) のとき　ψ′＝f′(x)·ef(x)　（肩の微分が前に降り、e はそのまま） ① 肩の増分：
Δf ≈ f′(x)·Δx　（傾き × 幅） ② e の増分：
ef＋Δf − ef ＝ ef(eΔf − 1) ≈ ef·Δf　（eΔf ≈ 1＋Δf：e は傾きが高さの1倍） ③ Δx で割る：
ψ′ ＝ Δψ/Δx ＝ f′(x)·ef(x)　／　平面波 f＝ikx なら f′＝ik、ガウス型 f＝−ax² なら f′＝−2ax
うさ美
納得しました。それなら ψ′ ＝ −2ax·A·e−ax² ＝ −2a×(xψ)。……本当に定数倍になりました！ 全然別物に見えた xψ と ψ′ が、最良の波の上ではぴったり重なっている。予言どおりです。λ＝2a と選べば λxψ＋ψ′ はどこでも 0、つまり I(λ)＝0。魔法の関数は、「最良の波からのズレ」を測る物差しだったんだ。最良の波なら、λ をうまく選べばズレをゼロにできる。それ以外の波では、どんな λ を選んでもゼロにはならず必ずプラス……。マイナスになることは、絶対値の2乗の足し合わせですから、どの波でもどの λ でもありえません。だから「足し算で混ぜる」のが正解だったんですね。ぐちゃぐちゃどころか、この2つは混ぜるために生まれてきたような組み合わせです。……ただ、いまのはガウス波束という特別な波で試しただけです。どんな波でも成り立つ証明には、まだなっていませんよね？
ガウス波束 ψ＝A·e−ax² では ψ′＝−2a·xψ。上の2本は上下が逆なだけの同じ形で、λ＝2a と選んで足すと完全に打ち消し合う。I(λ) は「最良の波（ガウス波束）からのズレ」を測っている
ねこ博士
その通り。いまやったのは証明ではなく、道具の設計チェックだ。I(λ) ≥ 0 そのものは、どんな波でも無条件に成り立つ。だからそこから出てくる不等式は、どんな波にも通用する。ガウス波束で確かめたのは、この道具が「最良の波で等号になれるほど鋭い」ということ――つまり出てくる不等式が ℏ/2 まで届く見込みがある、ということだけだ。本当に届くかどうかは、これから展開して確かめる。しかもその展開には、ガウス波束の性質は一切使わない。ハイゼンベルクの計算という答えを先に知っていたから、混ぜるべき相手も、混ぜ方が足し算であることも、こちらから決められた――これが「ゴールからの逆算」の使い方だよ。では狩りの型の②、展開に進もう。複素数の2乗の展開公式は |A＋B|²＝(A＋B)(A*＋B*)＝|A|²＋AB*＋A*B＋|B|²。A＝λxψ、B＝ψ′ を入れる。λ も x も実数だから A*＝λxψ* となって、真ん中の2項は λx(ψψ′*＋ψ*ψ′) とまとまるよ。
うさ美
括弧の中の ψψ′*＋ψ*ψ′、これ、見覚えがあります。積の微分公式です！ |ψ|²＝ψψ* を微分すると (ψψ*)′＝ψ′ψ*＋ψ(ψ*)′。同じものです。つまり真ん中の項は λx(|ψ|²)′。……あっ、だから補題1だったんですね。∫x(|ψ|²)′dx が証明のどこで出てくるのか不思議でしたが、ここで登場するために仕込んであったんだ。
ねこ博士
伏線回収だよ。それでは積分して、3つの項を道具箱の言葉に翻訳してごらん。λ² の項、λ の項、定数項の順でね。
うさ美
λ² の項は λ²∫x²|ψ|²dx ＝ (Δx)²λ²。λ の項は λ∫x(|ψ|²)′dx で、補題1からこの積分は −1、だから −λ。定数項は ∫|ψ′|²dx で、補題2から (Δp)²/ℏ²。全部そろって……I(λ) ＝ (Δx)²λ² − λ ＋ (Δp)²/ℏ²。これが、どんな λ でも0以上。
ねこ博士
立ち止まって、いま起きたことの凄みを味わってほしい。出発点には波動関数 ψ――無限にありうる、あらゆる波の形――がいた。ところが展開して道具箱で翻訳したら、ψ は式から完全に消えてしまった。残ったのは Δx と Δp という2つの数と、つまみ λ だけの、ただの二次関数だ。無限にある波の形を一網打尽にする仕掛けの正体はこれだよ。どんな ψ から出発しても、必ずこの同じ二次関数の形に流れ込む。
展開：
|λxψ＋ψ′|² ＝ λ²x²|ψ|² ＋ λx(|ψ|²)′ ＋ |ψ′|²　（真ん中は積の微分公式で束ねた） 積分して道具箱で翻訳： 　λ²∫x²|ψ|²dx ＝ (Δx)²λ²　／　λ∫x(|ψ|²)′dx ＝ −λ（補題1）　／　∫|ψ′|²dx ＝ (Δp)²/ℏ²（補題2） 【到達点】
I(λ) ＝ (Δx)²λ² − λ ＋ (Δp)²/ℏ² ≥ 0　（すべての実数 λ で）

「どんな λ を入れても0以上になる二次関数」……。グラフで言えば、下に凸の放物線が、横軸より下に一度も潜らないということですよね。放物線がそういう形になれる条件なら、学校で習った道具で書けそうな気がします。

確認クイズ

Q1. I(λ)＝∫|λxψ＋ψ′|²dx が、どんな λ でも必ず0以上になる理由は？

正解！ 「2乗は0以上」――STAGE1でばらつきを定義したときと同じ、いちばん素朴な事実が証明全体を支えている。(a−b)² ≥ 0 から a²＋b² ≥ 2ab を出した狩りの型の、積分版だ。

Q2. 2乗する中身として「xψ と ψ′ の混合」を選ぶ理由は？

正解！ 展開すれば |xψ|² と |ψ′|² の項が現れて、狙い通り (Δx)² と (Δp)² が式に登場する。さらにガウス波束では ψ′ が xψ の定数倍（ψ′＝−2a·xψ）になるので、この混合は「最良の波からのズレ」という意味まで持っている。

Q3. 展開後の式 (Δx)²λ² − λ ＋ (Δp)²/ℏ² に現れる「−λ」の係数 −1 の出どころは？

正解！ 「電子は必ずどこかにいる」という規格化条件が、部分積分を経由して −1 という数に化け、λ の1次の係数として証明の急所に座る。どんな波形でも同じ −1 になるのがポイントだ。
