STAGE 7

等号の波と歴史

ガウス波束とその後の物語
🎯 ミッション
等号 Δx·Δp＝ℏ/2 を達成する波がガウス波束だけであることを導き、ケナードから小澤まで続く「証明のその後」を知って旅を締めくくろう。
未達成
うさ美
最後に残った楽しみ、等号の話からお願いします。不等式 Δx·Δp ≥ ℏ/2 で、ちょうど等号になる――これ以上ないほど「引き締まった」波は、どんな形なんでしょう。STAGE5 の伏線からすると、答えはもう予想がついていますけど……。
ねこ博士
予想を証明に変えよう。等号になるのは、判別式の言葉で言えば D＝0、放物線が横軸に接するとき。接点の λ を λ₀ とすると、そこでは I(λ₀)＝0 だ。さて、I は「2乗の積分」――0以上の量の足し合わせだった。足し合わせがぴったり0になれるのは、どんなときかな。
うさ美
0以上のものを足して0になるなら、全部が0しかありえません。1か所でも正の場所があれば、合計は正になってしまいますから。つまり、中身がどこでも λ₀xψ＋ψ′＝0。移項すると ψ′＝−λ₀xψ――「微分すると −λ₀x 倍になる関数」を探せ、という問題になりました。……STAGE3 の規則が使えます。「肩を微分したものが前に降りてくる」のだから、降りてきたものが −λ₀x になる肩を探せばいい。微分して −λ₀x になる式は −λ₀x²/2 です。だから答えは ψ ＝ C·e−λ₀x²/2。
ねこ博士
その通り。検算すると、肩 −λ₀x²/2 の微分 −λ₀x が前に降りてきて、確かに ψ′＝−λ₀xψ を満たすね。さて、この形には名前がある。ガウス波束だ。山が釣鐘型――真ん中がいちばん高く、左右対称で、裾に向かってなだらかに、しかし速やかに 0 へ落ちる形――になっている波のことでね。前に付いている C は、規格化条件「|ψ|² の面積が 1」を満たすための定数だよ。山を細くすれば、面積を 1 に保つために高くなる。
ガウス波束では ψ′ が xψ の定数倍になる（A·e−ax² なら ψ′＝−2a·xψ）。上の2本は上下が逆なだけの同じ形で、λ₀ をうまく選んで足すと完全に打ち消し合い、λ₀xψ＋ψ′ がどこでも 0 になる。これが I(λ₀)＝0、つまり等号が成り立つ状態だ
1.00
ガウス波束 ψ＝A·e−ax²（金）と、その確率密度 |ψ|²＝A²e−2ax²（赤）。どちらも真ん中が最も高く、左右対称で、裾が速やかに 0 へ落ちる釣鐘型。A＝(2a/π)1/4 は規格化のための定数で、赤い山の面積は a をどう変えても 1――だから山を細くするほど高くなる。a を大きくすると山は細くなり、位置の標準偏差 Δx＝1/(2√a) は小さくなる。いっぽう細い山を作るには多くの波長を混ぜる必要があるので、運動量の標準偏差 Δp＝ℏ√a は大きくなる。積 Δx·Δp は a をどう選んでも ℏ/2 ぴったり――ハイゼンベルクが1927年の論文で確かめたのは、この計算だった
うさ美
釣鐘型……STAGE1 で出てきた誤差の釣鐘と同じ形ですね。星の位置を何度も測ったときの散らばりが、今度は波の形になって戻ってきた。……それに、山の幅を変えても積は ℏ/2 のまま動きません。細くしても太くしても、等号は保たれるんですか。
ねこ博士
そのとおり。そして実はハイゼンベルクは1927年の論文で、このガウス波束について Δx·Δp を計算して、ちょうど ℏ/2 になることを確かめていた。私たちがいま示したのは、その逆向きの事実だ――ℏ/2 をぴったり達成する波は、ガウス波束だけ。「最小不確定状態」と呼ばれる、量子力学でいちばん引き締まった波だよ。ハイゼンベルクが例として計算し、ケナードが特別な地位を証明した。レーザー光の理論などで、今も現役の主役だ。
等号の条件：
I(λ₀)＝0　⇔　すべての x で λ₀xψ＋ψ′＝0　⇔　ψ′＝−λ₀xψ 解：
ψ(x) ＝ C e−λ₀x²/2　（ガウス波束。これだけが Δx·Δp ＝ ℏ/2 を達成する）
波束A：位置を絞った（Δx小 → Δp大） 波束B：位置を広げた（Δx大 → Δp小）
2つのガウス波束 A・B について、位置の分布（左列）と運動量の分布（右列）を並べたもの。上段の A は位置を絞った波束で、そのぶん運動量が広がる。下段の B は位置を広げた波束で、運動量が締まる。片方を絞れば、もう片方が必ず広がる――シーソーのような関係だ。それでもどちらの波束も積は同じで、Δx·Δp＝ℏ/2 から動かない
うさ美
これで数学は完結ですね。……最後に、人の話を聞かせてください。この定理を証明したケナードという人のこと、私、名前しか知りません。ハイゼンベルクやアインシュタインと違って、この旅で初めて名前を知りました。
ねこ博士
アール・ヘッセ・ケナード（1885–1968）。アメリカのコーネル大学の物理学者だ。1926年から27年にかけてヨーロッパに渡り、ゲッティンゲンやコペンハーゲン――まさに量子力学が建設されている現場――に滞在していた。ハイゼンベルクの論文が出たのと同じ1927年、彼はドイツの学術誌に「単純な運動タイプの量子力学について」という論文を発表して、その中で、ばらつきを標準偏差で定義し、Δx·Δp ≥ ℏ/2 を任意の状態について成り立つ定理として初めて証明したんだ。
うさ美
私たちがたどった証明は、ケナードの論文に書いてあったそのままの道筋なんですか？
ねこ博士
正直に言うと、道筋は少し違う。ケナード自身は、波をいろいろな波長の成分に分解するフーリエ変換という道具立てで証明した。私たちがたどったのは、その後の人々が磨き上げた、いちばん道具の少ない最短ルートだよ。翌1928年には数学者ワイルが、教科書に載る有名な証明を著書で発表した――ワイル自身は「この証明はパウリに教わった」と記している。定理の中身はどれも同じで、定理はケナードのもの、証明の磨き上げはみんなのもの。数学ではよくあることなんだ。そして1929年、ロバートソンが決定版を出す。位置と運動量に限らず、どんな2つの測れる量のペアにも「ばらつきの積 ≥ ある量」という同じ型の不等式が成り立つことを証明したんだ。ただし右辺は ℏ/2 のような決まった定数ではなく、ペアごと・状態ごとに決まる量でね。位置の x 成分と y 成分のように両立できるペアでは右辺が 0 になって、何も制限しない。右辺が 0 にならないのが、スピンの縦向きと横向きのような「両立できない量」のペアで、そこにケナード型の制限がかかる。位置と運動量は、右辺がいつでも ℏ/2 という定数になる、いちばんきれいな場合だったわけだ。（よく似た名前で「エネルギーと時間」の関係も語られるけれど、あれは別の話でね。ロバートソンの定理が扱えるのは「測れる量」どうしのペアで、時間は測られる量ではなく、実験室の時計が刻む目盛りだからなんだ。）
うさ美
確認させてください。私たちが証明したのは「測る前の状態そのものが持つばらつき」の定理でした。ではハイゼンベルクの元々の直感――「観測すると乱してしまう」という話は、結局どうなったんですか？ あれはあれで、正しそうに聞こえるんですが。
ねこ博士
それが、この物語のいちばん驚くべき後日談だよ。「測定の誤差」と「測定が与える乱れ」の関係を厳密な定理にする仕事は、ケナードの定理とは別の、ずっと難しい問題だったんだ。きちんと定式化されたのは、なんと2003年。日本の数学者、小澤正直による「小澤の不等式」だ。ハイゼンベルクの直感が正確な定理の形になるまで、76年かかったことになる。そしてその小澤の不等式の中にも、ケナードの Δx や Δp はちゃんと部品として生きている。1927年の証明は、いまも現役なんだよ。
うさ美
着想したハイゼンベルク、定理にしたケナード、磨いたワイルとパウリ、広げたロバートソン、そして76年後に元の直感を救い出した小澤……。たった1行の不等式に、こんなに大勢の手が入っていたんですね。「ハイゼンベルクの不確定性原理」という名前だけでは、もったいない気がしてきました。
ねこ博士
だから物理学者は、あの不等式をしばしば「ケナードの不等式」と呼ぶんだ。着想の栄光はハイゼンベルクに、証明の栄光はケナードに。そしてきみはもう、その証明を人に説明できる側の人間だよ。最後にもう一度だけ、旅の全体を5行で振り返っておこう。
【証明の全体像・5行版】 ① ばらつきを標準偏差で定義：
(Δx)²＝∫x²|ψ|²dx,　(Δp)²＝ℏ²∫|ψ′|²dx（部分積分） ② 魔法の関数 I(λ)＝∫|λxψ＋ψ′|²dx ≥ 0 を、すべての実数 λ で考える ③ 展開して翻訳：
I(λ)＝(Δx)²λ² − λ ＋ (Δp)²/ℏ²（−1 は規格化条件の化身） ④ 常に0以上の二次関数だから判別式 ≤ 0：
1 − 4(Δx)²(Δp)²/ℏ² ≤ 0 ⑤ 整理して Δx·Δp ≥ ℏ/2。等号はガウス波束のみ ∎

確認クイズ

Q1. 等号 Δx·Δp＝ℏ/2 をぴったり達成する波動関数は？

正解！ I(λ₀)＝0 ⇔ λ₀xψ＋ψ′＝0 ⇔ ψ＝Ce−λ₀x²/2。2乗の積分が0になるには中身が恒等的に0になるしかなく、その条件を満たすのはガウス波束だけだ。

Q2. ケナードの定理と「観測すると乱してしまう」という話の関係は？

正解！ グループを分けて測るケナードの設定には「1回目の測定が2回目を乱す」余地がない。測定誤差と擾乱の定理化はずっと難しく、76年後の小澤の不等式でようやく実現した。

Q3. ロバートソン（1929）が付け加えたことは？

正解！ スピンの異なる向きどうしなど、量子力学の「両立できない量」のペアすべてに、ケナード型の不等式が一般化された。きみのたどった証明は、その一般化の原型だ。
