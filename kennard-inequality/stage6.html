STAGE 6判別式でフィニッシュ
中学数学が定理を倒す
🎯 ミッション
「すべての λ で0以上の二次関数は判別式が0以下」を使って、Δx·Δp ≥ ℏ/2 の証明を完成させよう。
未達成
ねこ博士
前のステージで手に入れた到達点を、あらためて眺めよう。I(λ) ＝ (Δx)²λ² − λ ＋ (Δp)²/ℏ² が、すべての実数 λ で0以上。λ² の係数 (Δx)² は正だから（ゼロの場合は後で退治する）、グラフは下に凸の放物線だ。ここから先は、きみのホームグラウンドだよ。放物線と横軸の位置関係を調べる道具を、学校で習っているね。
うさ美
判別式ですね。二次方程式 Aλ²＋Bλ＋C＝0 の解の公式に出てくる、ルートの中身 D＝B²−4AC。D が正なら解が2つ――つまり放物線は横軸と2点で交わる。D＝0 なら1点で接する。D が負なら交わらない。解の公式のルートの中がマイナスになったら実数の解なし、という、あれです。
ねこ博士
それで、「すべての λ で I(λ) ≥ 0」という条件は、D についての条件に言い換えられる。考えてごらん。もし D が正だったら、何が起きてしまうかな。
うさ美
D が正だと、放物線は横軸を2点で突き抜けます。下に凸ですから、2つの交点の間では放物線は横軸より下――I(λ) が負になる λ が存在してしまう。でも I(λ) は「2乗の積分」で、負には絶対なれません。矛盾です。だから D は正であってはならない。D ≤ 0 が必要です。接する（D＝0）のと、浮いている（D＜0）のはセーフですね。
I(λ) のグラフとして許されるのは、横軸より上（D＜0）か、接する（D＝0）まで。横軸を突き抜ける放物線（D＞0）は、負になる区間を持つので「2乗の積分」ではありえない。よって D ≤ 0
ねこ博士
では、いよいよフィニッシュだ。私たちの二次関数の係数は A＝(Δx)²、B＝−1、C＝(Δp)²/ℏ²。判別式 D＝B²−4AC に代入して、D ≤ 0 を整理してごらん。最後まで、きみの手で。
うさ美
代入します。D ＝ (−1)² − 4×(Δx)²×(Δp)²/ℏ² ＝ 1 − 4(Δx)²(Δp)²/ℏ² ≤ 0。1 を右に移項して、4(Δx)²(Δp)²/ℏ² ≥ 1。両辺に ℏ² を掛けて4で割ると、(Δx)²(Δp)² ≥ ℏ²/4。両辺とも0以上ですから、平方根をとって大小関係はそのまま……Δx·Δp ≥ ℏ/2。……出ました。出てしまいました。証明終わり、です……！
ねこ博士
おめでとう。それが、1927年にケナードが世界に示した定理だよ。きみはいま、その証明を最初の定義から最後の1行まで、自分の手でたどり切ったんだ。
判別式に代入：
D ＝ (−1)² − 4·(Δx)²·(Δp)²/ℏ² ＝ 1 − 4(Δx)²(Δp)²/ℏ² ≤ 0 整理すると：
(Δx)²(Δp)² ≥ ℏ²/4 平方根をとって――【定理（ケナード, 1927）】
Δx·Δp ≥ ℏ/2　∎
うさ美
振り返ると、使った道具は「2乗は0以上」「電子は必ずどこかにいる」「部分積分」「判別式」……たったこれだけです。宇宙のどんな粒子も、どんな最新技術でも破れない限界が、こんなに少ない道具から論理だけで出てくるなんて。それと、ハイゼンベルクの見積もり「およそ h」と比べると、正確な下限 ℏ/2＝h/4π は h の13分の1くらいですね。桁の見積もりとしては彼も良い線だったんだ。
ねこ博士
いい観察だ。ところで、さっき棚上げにした宿題を片付けておこう。判別式の議論は A＝(Δx)² が正であることを使った。では、もし Δx＝0――位置が完全に確定した状態――だったらどうなるか。I(λ) の式に A＝0 を入れて、考えてごらん。
うさ美
λ² の項が消えて、I(λ) ＝ −λ ＋ (Δp)²/ℏ²。これは傾き −1 の一次関数です。一次関数は、λ をどんどん大きくすればいくらでも下がっていく。つまりどこかで必ず負になります。「すべての λ で0以上」と矛盾……。ということは、そもそも Δx＝0 になる波動関数は存在しないんですね。位置が完全に確定した電子は、量子力学には存在を許されていない。
ねこ博士
その通り。穴は塞がって、証明は完全になった。残る楽しみはあと2つ。等号 Δx·Δp ＝ ℏ/2 をぴったり達成する波は何者なのか。そして、この定理を証明したケナードとは何者で、証明はその後どう磨かれていったのか。最終ステージで、物語を締めくくろう。
確認クイズ

Q1. 「すべての λ で I(λ) ≥ 0」から、判別式 D について言えることは？

正解！ 下に凸の放物線が横軸を突き抜けると、交点の間で必ず負になる。「2乗の積分」は負になれないので、D ≤ 0 しか許されない。

Q2. D ＝ 1 − 4(Δx)²(Δp)²/ℏ² ≤ 0 を整理すると？

正解！ 移項と平方根だけで、ケナードの定理 Δx·Δp ≥ ℏ/2 が完成する。1927年の物理学の最深部にとどめを刺したのは、中学校で習う判別式だった。

Q3. Δx＝0（λ² の係数がゼロ）の場合はどうなる？

正解！ I(λ)＝−λ＋(Δp)²/ℏ² は λ が大きいと必ず負になり、「すべての λ で0以上」に矛盾する。位置が完全に確定した状態は量子力学に存在しない――証明の穴を塞ぐと、おまけの定理まで手に入った。
