ねこ博士
今日の道具は、19世紀の解析学者たちが毎日のように振るった職人芸「部分積分」だ。出発点は、2つの関数の積を微分する規則。設定をはっきりさせておこう。f と g は、どちらも同じ入力 x で値が決まる関数――たとえば f(x)＝x²、g(x)＝x のようなものだ。x をひとつ決めれば f も g も値が決まり、掛け算 f×g も1つの値に決まる。x を変えれば f も g も動くから、積 f×g も動く。知りたいのは、その積が x とともにどれだけの速さで変わるか、つまり積の傾き (fg)′ だ。いい考え方があるよ。ある x での f の値を縦、g の値を横にした長方形を思い浮かべてごらん。面積が f×g だね。ここで x をほんの少し Δx だけ進める。すると f の値が Δf、g の値が Δg だけ変わって、長方形の縦と横が同時に少し伸びる。さて、面積はどれだけ増えるかな。
1.00 0.30
x＝1.00：f＝1.00、g＝1.00、面積 f×g＝1.00　→　x＋Δx＝1.30：Δf＝0.69、Δg＝0.30、増えた面積＝1.197
左：f と g は、どちらも同じ入力 x で値が決まる関数（例として f(x)＝x²、g(x)＝x）。x をひとつ決めると（黒い点線）、f の値と g の値が1つずつ決まる。x を Δx だけ進めると（青い点線）、f は Δf、g は Δg だけ変わる。右：その x での f を縦、g を横にした長方形で、面積が積 f×g。x が Δx 進むと縦と横が同時に伸び、増えた面積が青い帯2本と赤い角になる。x のスライダーを動かすと長方形そのものの大きさが変わり、Δx を動かすと帯と角の太さが変わる――x は長方形の軸ではなく、縦と横を同時に動かす「つまみ」だということが分かる
うさ美
展開してみます。(f＋Δf)(g＋Δg) − fg ＝ Δf·g ＋ f·Δg ＋ Δf·Δg。図で言うと、右に足される細長い帯と、上に足される細長い帯と、角の小さな正方形ですね。
積の微分公式の図解。長方形の面積 f×g の増え方は「帯2本ぶん」。微小×微小の角は極限で消える。これが (fg)′＝f′g＋fg′ の正体
ねこ博士
そう。ここで角の正方形に注目してほしい。Δf·Δg は「微小×微小」だ。たとえば Δf も Δg も 0.01 なら、2つの帯はそれぞれ 0.01×g、f×0.01 の桁なのに、角は 0.01×0.01＝0.0001――帯の100分の1しかない。だから極限では角は消えて、残るのは Δf·g ＋ f·Δg の2つの帯だけになる。
うさ美
角が消えるのは分かりました。でも帯にも Δ がついていて、Δ を小さくすれば帯だって同じようにゼロに向かいますよね。角だけが消えて帯が残る、という区別はどこから来るんですか？
ねこ博士
いい引っかかりだ。そのとおりで、そのままでは帯も角もどちらもゼロに向かう。違いが出るのは「傾き」を出すときだよ。前のステージで、微分は「増えた量 ÷ 進んだ幅 Δx」だったね。そこで Δf と Δg を Δx で書き直す。f の増分は「傾き × 進んだ幅」だから Δf ≈ f′·Δx、同じく Δg ≈ g′·Δx。すると2つの帯は Δf·g ＋ f·Δg ≈ (f′g ＋ fg′)·Δx で、Δx が1個。角は Δf·Δg ≈ f′g′·(Δx)² で、Δx が2個。面積の増え方を Δx で割ると、帯のほうは Δx が打ち消されて f′g ＋ fg′ という有限の値が残るのに、角のほうは f′g′·Δx と Δx が1個残る。だから Δx をゼロに近づけると、角の項だけが消える。数字で言えば、Δx＝0.01 のとき帯は割ったあとで f′g＋fg′ のまま、角は 0.01×f′g′。Δx＝0.001 なら角は 0.001×f′g′。帯は変わらず、角だけがどこまでも小さくなる。これが積の微分公式 (fg)′＝f′g＋fg′ だ。部分積分は、この公式の「逆再生」にすぎない。まず移項して f′g ＝ (fg)′ − fg′。この両辺を −∞ から ＋∞ まで積分する。右辺第1項の「(fg)′ の積分」は、傾きを足し集めたものだから、単純に両端での値の差になる（山道の傾きを全部足せば、ゴールとスタートの標高差になる、というのと同じ理屈だよ）。この「両端での値の差」を角かっこで [fg] と書く。中身の fg を、右端 b で見た値から左端 a で見た値を引いたもの、つまり [fg] ＝ f(b)g(b) − f(a)g(a) という意味の記号で、教科書では [fg]ₐᵇ のように端の名前を添えて書くこともある。

Δx＝0.400：帯 ÷ Δx ＝ f′g＋fg′ ＝ 3.00（一定）、角 ÷ Δx ＝ f′g′·Δx ＝ 0.800（Δx→0 で消える）
ここでの x は f と g の入力（この旅では位置）で、f と g はどちらも x の関数 f(x)、g(x)。長方形の縦横は「x をひとつ決めたときの f と g の値」なので、長方形の図に x の軸は描かれていない。x を Δx だけ進めると、縦と横が同時に少しずつ変わる。上の段（積の微分公式）：縦 f、横 g の長方形（上の図と同じ f(x)＝x²、g(x)＝x を x＝1 で見たもの。f＝1、g＝1、傾き f′＝2、g′＝1）で、x が Δx 進むと、縦が Δf＝f′Δx、横が Δg＝g′Δx だけ育つ。増えた面積は青い帯2本 Δf·g＋f·Δg と赤い角 Δf·Δg。そのままでは Δx を小さくするとどれもゼロに向かうが、傾きを出すためにΔx で割ると（右上の棒）、帯は Δx が打ち消されて f′g＋fg′ で一定、角は f′g′·Δx と Δx が1個残る。スライダーで Δx を小さくしていくと、帯の棒は動かず角の棒だけが消えていく――これが (fg)′＝f′g＋fg′。下の段（傾きの足し集め）：同じ f(x)＝x²、g(x)＝x の積 h＝fg＝x³ を山道の標高とすると（x が増えるほど登り続ける道）、その傾き (fg)′ を a から b まで足し集めたもの（右下の色のついた面積）は、ゴールとスタートの標高差 [fg]（左下の赤い縦線）にちょうど等しい。ゴール b を動かしても、面積と標高差はつねに一致する。波動関数が絡む場合は、遠方でどちらの標高も 0 なので、この差 [fg] はまるごと消える

ここまでの図は f(x)＝x²、g(x)＝x という簡単な例だったが、積の微分公式も「傾きの足し集め＝両端の差」も、どんな f、g でも成り立つ。この図は増えたり減ったりする一般の関数の例で、横が x、高さが f、手前が g の空間に、点 (x, f(x), g(x)) の軌跡を1本の曲線として描いたもの（壁に落ちた点線の影が、それぞれ f(x) と g(x) のグラフ）。x をひとつ決めると曲線上の1点が決まり、その位置に縦 f(x)・横 g(x) の長方形を立てられる――面積が積 f×g。x を Δx 進めると長方形は隣の位置に移り、縦横が変わる（青）。増えたぶんが帯2本と角で、f や g が減る場所では帯が負になる（薄い青）が、「面積の変化 ＝ Δf·g ＋ f·Δg ＋ Δf·Δg」はどこでも同じ形で成り立つ。角 Δf·Δg だけが Δx² の桁で、割ると消える――ここも簡単な例と変わらない。下の段：左は長方形の面積 fg を x の関数として描いたもので、金の点から青の点へ登る赤い坂が「Δx で増えた面積」。右はその傾き (fg)′＝f′g＋fg′ のグラフ（0 より上なら面積が増える場所、下なら減る場所）。赤い輪は「増えた面積 ÷ Δx」で測った坂の傾きで、Δx を小さくしていくと (fg)′ の値（金の点）にぴったり重なる――これが「角が消えて帯だけが残る」ことの、グラフでの姿。さらに区間 a〜b の積分：右のグラフで (fg)′ を a から b まで足し集める（0 より上の金の面積を＋、下の青の面積を−として合計する）と、左のグラフのゴール b とスタート a の標高差 fg(b)−fg(a)、すなわち [fg] にぴったり一致する。3D図で言えば、b の位置の長方形の面積から a の位置の長方形の面積を引いたもの。b を動かしても等式はつねに成り立ち、途中で下り（青）があれば、その分だけ [fg] は小さくなる

そして私たちの相手は波動関数。前のステージまでの約束で、遠方では ψ → 0 でした。電子は無限の彼方にはいないから。ということは、f や g に ψ が絡んでいるかぎり、「両端での値」はどちらも0。差の [fg] はまるごと消えます！
ねこ博士
その通り。だから物理の計算では、部分積分はこう覚えるのが実戦的だ――「積分の中の微分は、相手の関数に押し付けられる。ただし符号が反転する」。∫f′g dx ＝ −∫fg′ dx。意味はこうだ。左辺では微分の印 ′ が f に付いている。それを右辺では g のほうに付け替えてよい、ただし全体にマイナスが付く――さっきの式 ∫f′g dx ＝ [fg] − ∫fg′ dx で [fg] が消えた形そのものだね。なぜマイナスかは、長方形の絵で分かる。f′g と fg′ は面積が育つ2本の帯で、足せば面積 fg の変化になる。ところが遠方では fg が 0 から出発して 0 に戻るのだから、変化の合計は 0。つまり2本の帯の合計はちょうど打ち消し合う――f が育てたぶんは、g が減らしたぶんに等しい。だから片方の帯の合計は、もう片方の合計にマイナスを付けたものになる。この「押し付けの術」が今日の魔法だよ。さっそく1発目の弾丸を作ろう。証明で後で出会うことになる、こんな積分だ：∫ x (|ψ|²)′ dx。x と、「|ψ|² の微分」の積の積分。押し付けの術を使ってごらん。
うさ美
微分が (|ψ|²) に付いているので、これを相手の x に押し付けます。符号を反転して、∫ x (|ψ|²)′ dx ＝ −∫ x′ |ψ|² dx。x を微分したら……傾き1の直線だから x′＝1。つまり −∫ |ψ|² dx。えっ、これ、規格化条件の積分そのものじゃないですか。値は1と決まっています。答えは −1！
ねこ博士
その通り、それが補題1だ。ここで起きたことをよく味わってほしいんだ。波の形が何であれ――ガウス型でも、ギザギザでも、二山でも――この積分は必ず −1 になる。「電子は必ずどこかにいる」という物理の当たり前が、−1 という具体的な数に化けた。無限にある波の形を一網打尽にする仕掛けの、これが最初の歯車だよ。

いいよ、入れ替えられる。理由は絵で分かる。共役とは虚部の符号を反転すること――複素数の平面で言えば、矢印を実軸で折り返した鏡像にすることだ。いっぽう微分は、隣り合う x と x＋Δx の2本の矢印の差を Δx で割ったもの。2本の矢印を先に鏡に映してから差を取っても、先に差を取ってからその差を鏡に映しても、出てくる矢印は同じだ――鏡像は足し算や引き算をそのまま保つからね。だから (ψ*)′ ＝ (ψ′)*。

確認クイズ

Q1. 部分積分を使うと、∫f′g dx はどう書き換えられる？（ψ が絡む場合）

正解！ 積の微分公式の逆再生で ∫f′g dx＝[fg]−∫fg′dx。波動関数は遠方でゼロだから境界項が消え、「押し付けると符号反転」だけが残る。

Q2. 境界項 [fg] が消えるのはなぜ？

正解！ [fg] は「両端での値の差」。電子がどこか有限の範囲に局在している以上、±∞ での値はゼロ。物理の事実が数学の計算を軽くしてくれる場面だ。

Q3. 補題2「(Δp)²＝ℏ²∫|ψ′|²dx」が語っていることは？

正解！ 傾きの急な波形ほど Δp が大きい。「波の細かさ＝運動量」という直感が、部分積分によって正確な等式になった。
